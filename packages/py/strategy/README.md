# Strategy

## Frozen v1 baseline

The `v1` baseline is frozen. Its parameter set is intentionally empty: this
package currently defines no configurable strategy parameters or defaults.

| Parameter | Frozen v1 value |
| --- | --- |
| Algorithm parameters | None |
| Runtime overrides | None |

Adding a parameter, assigning a default, or allowing an override changes the
baseline and requires a new strategy version. Documentation-only corrections
that do not alter the parameter set may retain the `v1` designation.
