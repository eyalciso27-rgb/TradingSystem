# Trading application

## Frozen baseline strategy v1

The trading application's strategy manifest freezes baseline `v1` with an
empty parameter set. There are no configurable strategy parameters, default
values, or runtime overrides in this version.

| Manifest field | Frozen v1 value |
| --- | --- |
| Strategy version | `v1` |
| Algorithm parameters | None |
| Default parameter values | None |
| Runtime parameter overrides | None |

Adding a parameter, assigning a default, or permitting an override changes the
frozen baseline and requires a new strategy version. Documentation corrections
that do not alter the parameter set may retain the `v1` designation.
